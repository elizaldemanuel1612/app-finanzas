# Estados

Cada pantalla define sus tres estados; ninguno es una pantalla en blanco.

- **Vacío**: qué va a aparecer aquí y el primer paso, con un botón. Si hay datos del plan, se muestran (un usuario nuevo ya sabe cuánto puede gastar hoy).
- **Carga**: skeleton con la forma real del contenido en `superficie-hundida`. Sin spinners de pantalla completa. Con "reducir movimiento", sin brillo animado.
- **Error**: qué pasó, tranquilidad ("tus datos están a salvo") y Reintentar.
