# Tarjeta

Un solo componente con tres variantes. Sustituye los 5 estilos de tarjeta anteriores.

- **Héroe**: fondo `heroe-fondo`, máximo una por pantalla, solo para la cifra que responde la pregunta de la pantalla.
- **Informativa**: `superficie`, borde `borde`, `sombra-1`, radio `radio-l`, padding 16.
- **De lista**: la misma superficie con renglones separados por `borde`. Las listas nunca son tarjetas sueltas.
- Las alertas no tiñen tarjetas completas: usan Aviso.
- No: tarjetas dentro de tarjetas; bordes de color a la izquierda; degradados.
