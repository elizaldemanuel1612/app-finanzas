# Hoja

Hojas para tareas cortas sin perder el contexto; diálogos solo para confirmar algo que cambia datos.

- Hoja: esquinas `radio-xl`, agarradera, velo `velo`, cierra con deslizar o tocar el velo. Un primario al final.
- Diálogo: título en pregunta, una frase de consecuencia, dos botones (el que confirma dice el verbo).
- No: diálogos para informar; hojas con scroll de más de una pantalla.
