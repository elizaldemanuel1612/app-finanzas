# Chip

Los chips eligen; el control segmentado cambia de vista dentro de la misma pantalla.

- Chip: alto visual 36, área táctil 44. Seleccionado = `accion` con check (la forma acompaña al color).
- Los filtros se pueden combinar; los chips de selección son excluyentes.
- Segmentado: 2 o 3 opciones, nunca más. La opción activa se eleva sobre `superficie-hundida`.
- No: chips para navegar a otra pantalla; más de una fila de filtros sin scroll horizontal.
